# Tools this skill uses

All four are read-only tools of Spellwarden's MCP server.

- `list_agent_space_connections`: this integration's connections and their last sync.
- `list_skills`: the organisation's skills with scan status and trust score.
- `list_mcp_servers`: the organisation's MCP servers with classification and finding counts.
- `list_findings`: findings, filtered by status and severity.
