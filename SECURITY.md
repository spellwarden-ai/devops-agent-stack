# Security

To report a security problem, write privately to security@spellwarden.ai. Please do not open a public issue for it.

Say what you found, where, and how to reproduce it. We read every report and answer it.

The template holds one inline function of under 4096 characters that calls only Spellwarden (register, asked again for a few seconds while a new role becomes usable, and unregister) and never calls DevOps Agent.
